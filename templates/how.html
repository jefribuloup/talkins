Cara kerja Talkins

Dari file Excel ke jawaban, rumus, dan slide. File aslimu tidak pernah tersentuh.

01 Unggah 02 Rapikan 03 Rumus 04 Tanya 05 Hasil
  1. 01

    Unggah file Excel-mu

    Tarik file .xlsx ke Ruang unggah, atau tempel link. File yang besar bisa lewat Google Drive. Talkins langsung membuat salinan kerja di cloud, jadi file di komputermu tidak disentuh.

    penjualan.xlsx ↓ Salinan kerja dibuat
  2. 02

    Lihat dan rapikan datanya

    Sheet tampil persis seperti di Excel: baris 1, 2, 3 dan kolom A, B, C. Rapikan lewat toolbar, lalu lanjut. Salah langkah? Satu klik untuk kembali ke data awal.

    Buang baris kosong Buang duplikat Urutkan kolom Filter baris Ubah ke angka Reset ke asli
  3. 03

    Pilih sel, dapat saran rumus

    Blok beberapa sel lalu buka tab Rumus. Talkins menyarankan rumus Excel lengkap dengan hasilnya.

    • Klik Salin pada rumus yang kamu mau.
    • Klik sel mana saja, termasuk sel yang masih kosong.
    • Tekan Ctrl+V. Rumus langsung dihitung dan hasilnya muncul di sel itu.
    AB 1Budi100 2Sari250,5 3Andi75 4…425,5
    =SUM(B1:B3)→ B4
  4. 04

    Ngobrol dan lihat rekap

    Tanya apa saja soal isi data di tab Chat. Tab Rekap merangkum kesehatan data: sel kosong, pencilan, dan komposisi kategori.

    Jadikan slide atau unduh

    Ubah datamu jadi slide, atau unduh hasil kerjamu sebagai file Excel baru. File aslimu tetap seperti semula.

Aman untuk file aslimu

File di komputermu tidak pernah diubah. Yang kamu kerjakan adalah salinan di cloud.

Bisa diulang

Semua perubahan terjadi di salinan kerja. Reset ke asli mengembalikannya kapan saja.

Hasil jadi file baru

Unduh salinan menghasilkan file Excel baru, bukan menimpa file lamamu.

Pertanyaan umum

Rumus apa saja yang bisa ditempel ke sel?

Semua rumus yang disarankan tab Rumus (SUM, AVERAGE, COUNTIF, SUMIF, VLOOKUP, dan lainnya), plus yang umum dipakai seperti IF, IFERROR, ROUND, TEXT, dan LEFT/RIGHT/MID. Pemisah argumen boleh koma atau titik koma. Rumus yang merujuk sheet lain belum didukung.

Bagaimana kalau rumus yang kutempel salah?

Pesan galat muncul dan kotak edit sel tetap terbuka supaya bisa kamu perbaiki. Galat hitungan seperti #DIV/0! ditampilkan di sel, sama seperti Excel.

Kenapa rumus saya berubah jadi angka biasa setelah mengurutkan?

Urutkan, filter, buang duplikat, dan hapus kolom menggeser posisi sel, jadi alamat di dalam rumus tidak berlaku lagi. Hasil hitungnya tetap ada sebagai angka biasa.

File saya besar, bagaimana mengunggahnya?

Kalau melewati batas unggah langsung, pakai link atau unggah lewat Google Drive dari Ruang unggah.
